# 绩效权限、兼职分部门与终极管理员总览

实施日期：2026-10-23 至 2026-10-25。

## 权限与计分

| 操作 | 开放身份 | 部门范围 |
| --- | --- | --- |
| 志愿者日常绩效录入 | 负责人、主席团、终极管理员 | 本部门／分管部门／全部门 |
| 负责人日常绩效录入 | 主席团、终极管理员 | 分管部门／全部门 |
| 志愿者学期上级逐项评分 | 负责人、主席团 | 本部门／分管部门 |
| 负责人学期上级逐项评分 | 主席团 | 分管部门 |
| 本人自评 | 志愿者、负责人 | 本人任职部门 |
| 志愿者评议负责人 | 志愿者 | 本人任职部门 |
| 志愿者互评、负责人互评 | 同类成员 | 同部门，排除本人 |

日常记录作为上级逐项评分的依据，可预填对应维度，仍需评分人核对提交。上级评分平均分 × 70% ＋ 自评 × 10% ＋ 同伴评价 × 20%；保留既有部门额外加分规则。负责人同伴部分保留负责人互评和志愿者评议，按现有来源平均规则计算。三部分未齐全显示待完成。

新增负责人日常录分入口，使用负责人计划落实、团队协作、成员指导、责任履行四个维度。志愿者继续使用各部门自己的制度。

## 兼职与归档

- 终极管理员在组织架构编辑志愿者，保留主要部门，勾选兼职部门。同一个账号无需重复创建。
- 成员权限、活动名单、日常流水、学期评价和归档按组织＋部门分别保存。
- 评价唯一索引增加组织和部门；先建立新索引，再移除旧四字段唯一约束，保留旧数据。
- 从一个部门移除志愿者，保留其他任职。任职历史与分部门归档保留，归档排名也在各部门内计算。
- 已归档绩效不能通过旧删除／校准接口继续修改。旧全局名单入口遇到兼职成员时提示改用部门工作台，避免整份替换抹掉其他部门名单。
- 志愿者可查看自己在当前部门的日常记录；可以重载自己给负责人提交的评价，不能查看他人给该负责人的评价。

## 终极管理员绩效总览

独立入口 `/performance-overview`；首页和平台管理内均有入口。后端 `/api/ultimate/performance-overview` 仅终极管理员可访问。

总览展示九部门的成员数、日常记录数、上级评分／自评／同伴评价覆盖人数、完整成绩数、已归档数。可按学期查看、展开部门和成员，查看逐项评价、流水、总分和雷达图，筛选负责人／志愿者／待完成成员，并进入部门工作台或组织归档。

页面可见时每 30 秒刷新，回到页面时刷新，失败明确提示保留的是上次成功数据。兼职按部门任职计数，不将两个部门合并为一个成绩。进度是已有相应评价的成员数，不表示所有应评价人都已提交。没有成员的部门显示 0/0，不算全部完成。

开放／关闭期末评价使用原有学期全局开关，历史学期只读，操作需要界面确认。部署不主动更改开放状态。
